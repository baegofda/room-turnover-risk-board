## 검증 방법

### 가설

[03. 문제 정의](./03-problem.md)의 가설 가운데 과제 안에서 확인할 수 있는 건 H1뿐이에요. 나머지는 실제 운영 데이터가 있어야 검증할 수 있어서 방법만 정해 둡니다.

| 가설 | 과제 안에서 | 실제로 검증하려면 |
|---|---|---|
| H1 인력 순서 때문에 늦는 객실이 있다 | 샘플에서 객실별로만 본 결과와 청소 순서를 따라간 결과를 비교해요 | 청소 기록과 체크인 지연 기록으로 얼마나 자주 생기는지 셉니다 |
| H2 안내 발송 전에 알면 대응 비용이 낮다 | 지점 안내에서 확인한 운영 방식으로 근거만 보여 줘요 | 발견 시점별로 객실 변경, 보상, 문의 건수를 비교해요 |
| H3 이유와 남은 시간이 있으면 바로 행동한다 | 판정 문장 예시를 보여 줘요 | 관제 담당자 인터뷰, 판정부터 대응까지 걸린 시간 |
| H4 청소 시간은 객실 타입, 숙박 일수, 인원으로 추정된다 | 가정값이라고 밝히고 함수로 분리해요 | 청소 시작과 완료 기록으로 오차를 재요 |

### 테스트

| 층 | 무엇을 확인하나 |
|---|---|
| 명세 규칙 | 명세의 규칙마다 테스트를 하나 이상 둬요. 경계값, 자정을 넘기는 체크인, 연박 객실, 받지 않는 입력, 기본 규칙의 반례가 여기에 들어가요 |
| 시나리오 | 샘플 입력마다 기대 결과를 파일로 고정하고 계산 결과와 비교해요 |
| 항상 지켜야 할 조건 | 같은 입력이면 같은 결과가 나와요. 청소할 객실이 결과에서 빠지지 않아요. 한 사람의 작업 시간이 서로 겹치지 않아요. 청소는 손님이 나가고 인력이 손이 빈 뒤에만 시작해요 |

"청소 인력을 늘리면 위험 객실이 줄어든다"는 항상 지켜야 할 조건에 넣지 않아요. 기본 규칙에서는 사람을 늘렸는데 결과가 나빠지는 경우가 있을 수 있어서 명세의 한계로만 적어 둡니다.
